# ⭐ Featured Projects

## 🎓 AI Study Planner — NEW

**Next.js · React · Tailwind CSS · Gemini AI · PDF Parsing**

An AI-powered study workflow that turns a student's syllabus PDF into a structured academic map, generates unit-specific quizzes, identifies weak topics, and creates a personalized day-by-day study plan.

### Current V0.4 flow

```text
Syllabus PDF
    ↓
PDF text extraction
    ↓
Gemini AI syllabus analysis
    ↓
Subjects → Units → Topics
    ↓
Unit-specific quiz
    ↓
Answers + explanations + score
    ↓
Weak-topic detection
    ↓
Exam date + daily study time
    ↓
Personalized study plan
```

**Highlights**
- 📄 Upload and parse syllabus PDFs
- 🤖 AI-powered subject, unit and topic extraction
- 🎯 Unit-focused quiz generation
- ✅ Automatic answer checking and explanations
- 📊 Score calculation and weak-topic detection
- 📅 Personalized study plan based on exam date and available study time
- 🔐 Gemini API key kept server-side
- 🧠 Chunked processing for large syllabus PDFs

A real **27-page syllabus PDF with 48,918 extracted characters** has been processed successfully through the pipeline.

🔗 **[Repository](https://github.com/shivamsinghrajputtt/ai-study-planner)**
